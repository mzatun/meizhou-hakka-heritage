## 〇、结论先行

**✅ 高可行，且主题比迁徙更适合地图可视化**——「城市变迁」本质是**政区边界 + 城垣扩张 + 城区格局**在时间轴上的演变，这正是时序 GIS 的教科书场景，与你的长卷 v3（MapLibre）技术栈**高度同源**。

**主线**（城市本体演变，四层递进）：
1. **政区地位**：程乡 → 敬州 → 梅州 → 嘉应州 → 梅县 → 梅州市（"名"的变迁）
2. **城垣扩张**：北宋土城 450 丈 → 明扩城 985 丈 → 清末东西两堡 → 现代城区（"形"的变迁）
3. **城区格局**：江北老城 → 江南新城 → 一江两岸（"里"的变迁）
4. **地标营建**：金山顶、攀桂坊、红杏坊、曾井、学宫、书院（"点"的变迁）

**佐证层**（不作主线，仅数据面板）：
- 科举人物流动（文化之乡佐证）→ 桑基图/流场
- 侨乡联系（开放之城佐证）→ 南洋弧线
- 客家源流（背景卡片，不展开——你已做迁徙长卷）

**一句话**：**迁徙长卷 v3 的技术资产（MapLibre 国风 + 时间轴 + 标记叙事）几乎原样复用，只换数据**；CBDB 架构只借用「React 外壳 + REST 模式 + 桑基图/谱系组件 + 认证埋点」。

## 一、主题定位：梅州城市变迁「讲什么」

### 1.1 城市变迁叙事线（主线，均有史料支撑）

| 维度 | 时间锚点 | 变迁内容 | 可视化 |
|---|---|---|---|
| **政区地位** | 479 → 2026 | 程乡县→敬州→梅州→梅州路→程乡县→嘉应直隶州→嘉应府(5年)→嘉应州→梅县→梅州市 | 时间轴 + 名称/边界动画 |
| **城垣扩张** | 1052 → 清末 | 北宋皇祐筑土城(周长450.3丈≈1499m) → 明洪武扩城(985丈≈3280m) → 清末东街西街两堡 | 城墙多边形序列动画 |
| **城区格局** | 清末 → 现代 | 江北老城两堡 → 江南公社 → 一江两岸 | 建成区范围渐变 |
| **地标营建** | 宋 → 现代 | 金山顶、攀桂坊、红杏坊、曾井、梅州学宫、东山书院、松口古镇 | 地标 POI 叙事 |
| **行政沿革** | 1949 → 1988 | 兴梅专区→汕头→梅县专区→梅州市(地级) | 专区边界动画 |

### 1.2 城垣营建史（最硬核的"城市变迁"素材，官方史料完整）

梅州城垣演变有明确的建城纪年，是地图动画的**黄金素材**：

| 年份 | 事件 | 数据点 |
|---|---|---|
| 南朝齐（479-502） | 置程乡县，500 多年无城 | 无城郭 |
| 北宋皇祐四年（1052） | **始筑土城**于梅城江北，周长 450.3 丈（约 1499m） | 第一道城墙 |
| 明洪武十八年（1385） | **拆西城垣扩城**，周长 985 丈（约 3280m） | 城市扩大约 2.2 倍 |
| 清末 | 城区辖东街、西街 2 堡（东街含攀桂坊/金山甲，西街含红杏坊/曾井甲） | 街坊格局定型 |
| 民国 20 年（1931） | 堡改区乡，县城辖附城镇等 | 现代区划雏形 |
| 民国 26 年（1937） | 县城称**梅城镇** | 城市定名 |
| 1975-1983 | 梅州镇→县级梅州市→梅县市 | 城市升格 |
| 1988 | 地级梅州市，新设梅江区 | 现代城市格局 |
| 2013 | 梅县改区 | 2区5县1市定型 |

**这是"一座城怎么长大"的完整时间轴**——1052 年 1.5 公里土城，到今天几十平方公里城区，比任何数据都能直观讲"城市变迁"。

### 1.3 城区空间结构（"一江两岸"的地理叙事）

- **江北老城**：金山顶（老城制高点）、攀桂坊（科举文脉）、红杏坊（商贸老街）、曾井（古城饮水）
- **江南新城**：1978 年后跨梅江发展，行政/商业南移
- **一江两岸**：梅江穿城而过，桥（梅江桥/剑英纪念大桥）连接两岸——城市沿江扩展的空间逻辑
- **城市地标**：梅州学宫、东山书院、凌风东路骑楼街、松口古镇（侨乡门户）

### 2.2 数据模型设计（核心：时间轴驱动的城市演变）

```jsonc

{
  "timeline": [
    { "year": 479, "name": "程鄉縣", "adminLevel": "縣", "subordinateTo": "潮州", "cityWalls": null },

    { "year": 1385, "name": "程鄉縣", "adminLevel": "縣",
      "cityWalls": { "material": "磚城", "perimeterM": 3280, "location": "江北", "expanded": true } }, // 扩城2.2倍

{
  "urbanGrowth": [
    { "year": 1052, "areaKm2": 0.2, "geom": "..." },   // 土城

    { "year": 2026, "areaKm2": 60, "geom": "..." }     // 一江两岸
  ]
}

// ★ 核心模型3：地标营建（POI 叙事）
{
  "landmarks": [
    { "name": "金山頂", "lon": 116.12, "lat": 24.30, "year": 1052, "type": "制高點", "story": "老城至高点" },

    { "name": "梅州學宮", "lon": 116.12, "lat": 24.29, "year": 宋, "type": "文教", "story": "文天祥题'忠孝廉节'" },
    { "name": "東山書院", "lon": 116.14, "lat": 24.28, "year": 清, "type": "文教", "story": "黄遵宪读书处" },
    { "name": "松口古鎮", "lon": 116.37, "lat": 24.44, "year": 清, "type": "僑鄉", "story": "联合国移民纪念项目" }
  ]
}

// 佐证模型（不作主线）：人物流动 edges（文化之城佐证，复用 CBDB 架构）
{
  "edges": [
    { "entryType": "進士類", "originName": "嘉應直隸州", "originLon": 116.12, "originLat": 24.29,
      "destinationName": "京師", "destinationLon": 116.41, "destinationLat": 39.90, "count": 5 }

```

**核心设计原则**：城市变迁的三个核心模型（政区/城垣 timeline、城区扩张 polygon、地标 POI）**全部是时间轴驱动的静态+动态图层**——这正是 MapLibre `setData` + 时间滑块的标准玩法，**比 CBDB 的流场更简单、更稳**。

## 五、双师视角价值

### 🎓 教学向

1. **"一座城的千年"是 GIS 时序动画最佳教案**：政区边界动画（政区沿革）+ 城垣扩张动画（城市建设史）+ 城区渐变（城市地理学）三合一，比迁徙线更贴合《城市地理学》《历史地理学》《GIS 动画》课程。
2. **城垣数据化是测绘史教学素材**：450 丈→985 丈的扩城史，可结合古代度量衡、地图配准（老地图 georeferencing）做实训。
3. 佐证面板（科举/侨乡）保留人文厚度，适合跨学科选题。

### 🏭 产学研向

1. **城市变迁 = 可复制产品模板**：任何城市都有"政区沿革+城垣+地标"数据，梅州验证后可横向复制（潮州/赣州/嘉应五属各城）。
2. **合作对象**：梅州市方志办/规划局/文广旅局（官方资料+老地图）、剑英图书馆（老地图/文献）、嘉应学院地理系（学生实训+数据采集）。
3. **应用场景**：方志馆数字展厅、城市规划展馆、文旅导览、中小学乡土教育。
4. **"老地图配准"是差异化能力**：历史地图 georeferencing 是 GIS 专业服务，可作 OPC 服务沉淀。

## 七、总结

> **可行性结论：高可行，且是"资产复用率最高"的方案。**
>
> 1. **主线清晰**：政区地位 × 城垣扩张 × 城区格局 × 地标营建——四层递进讲"一座城的千年"，全部有官方史料。
> 2. **数据最轻**：核心 timeline 数据官方已齐全（本文给出骨架），唯一硬骨头是城垣 polygon 绘制（1-2 天）。
> 3. **技术最省**：长卷 v3 的 MapLibre 资产几乎原样复用，CBDB 只借外壳与佐证组件，不引入 Three.js。
> 4. **价值双线**：教学（时序 GIS 教案）× 产学研（城市变迁产品模板 + 老地图配准服务）。
> 5. **与迁徙版的关系**：迁徙线已完成（长卷 v3），本方案只用其技术资产，主题不重叠。
