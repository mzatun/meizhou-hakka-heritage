# 历史资料 ↔ 地图联动设计说明（POI / AOI / 路径）

> 配套数据：`data/meizhou_timeline_v2.json`（时间线）、`data/meizhou_people.json`（人物）、`data/meizhou_events.json`（事件）、`data/meizhou_wards.json`（坊巷 AOI）
> 日期：2026-08-11

---

## 一、核心问题：历史资料如何"落到地图上"？

历史资料本质是**有时间、有地点、有情节的文本**。要让它们与地图联动，先解决"空间化"问题——把文本中的地点信息转成三种可渲染的空间形态：

```
历史资料
   │
   ├─ 点状信息 ──→ POI（Point of Interest，点要素）────→ 城门/故里/书院/井泉/碑刻/老建筑
   │
   ├─ 面状信息 ──→ AOI（Area of Interest，面要素）────→ 坊巷范围/城墙圈/历代城区/遗址带
   │
   └─ 流动信息 ──→ PATH（路径/弧线）─────────────────→ 人物任官路/迁徙路线/侨乡航线
```

**判定规则**（给数据打标签时的依据）：

| 信息形态 | 判定标准 | 示例 |
|---|---|---|
| POI 点 | 有明确坐标或可用"今址"定位（精度 ±100m 内） | 东门（仲元东路）、人境庐、大觉寺 |
| AOI 面 | 有明确范围或可推定边界（坊巷/城区/遗址带） | 攀桂坊、北宋土城圈、城墙遗址带 |
| PATH 弧线 | 两地之间的流动关系（人/物/信息的位移） | 蔡蒙吉→韶州、松口→曼谷 |

## 二、联动机制：四个"绑定"

### 2.1 时间绑定（时间轴过滤）

每条记录带 `year` 字段。时间轴移动时，地图只显示 **"该年代已存在"** 的 POI/AOI：

```
t=1052  → 显示：土城墙圈(AOI)、金山顶、城垣四门、梅城书院
t=1385  → 增加：五门齐全、文保路(叶文保)、砖城墙圈
t=1932  → 隐藏：城墙（已拆）→ 改显城墙遗址带(AOI)、骑楼街
t=2026  → 显示：现代城区、松口、客家博物馆
```

实现要点：MapLibre 图层 `filter: ["<=", ["get","year"], 当前年份]`，或 `setData` 前按 year 过滤 FeatureCollection——**数据不变，过滤驱动**。

### 2.2 空间绑定（POI/AOI 渲染）

- **POI 点** → MapLibre `circle` 图层 + DOM Marker 标签（现有 `addLabel` 能力可直接复用）
- **AOI 面** → MapLibre `fill` + `line` 图层（现有 county-fill 同款，半透明填充 + 描边）
- 点击 POI/AOI → 弹出**故事卡**（见 2.4）

### 2.3 人物绑定（POI + PATH 双联动）

人物数据同时携带 `home`（故里 POI）和 `career[]`（任官地列表）：

```
点击人物卡（如黄遵宪）
   ├─ 地图聚焦 → 人境庐 POI（116.116, 24.308）
   └─ 画出 4 条弧线 PATH：
        梅州 → 日本 → 旧金山 → 伦敦 → 新加坡
        （CubicBezier 抬升控制点，复用 CBDB 流线思路）
```

这就是"梅州人走向世界"的流动叙事——一个人物的履历变成地图上的弧线网。

### 2.4 故事绑定（可追溯）

每个 POI/AOI/PATH 关联一条 `story`（3-5 段）与 `source`（可追溯链接）。故事卡渲染：

```
┌──────────────────────────────┐
│ 攀桂坊（AOI，1326年杨圭立坊）    │
│ ──────────────────────────────│
│ 元天历三年，乡贡进士杨圭在老城东边│
│ 竖立'攀桂坊'坊表……             │
│ 📊 科甲统计：进士17 · 文举72 ·   │
│    武举15 · 共104               │
│ 🏠 坊内建筑：人境庐/攀桂书院/    │
│    桐花书屋（可点击跳转）        │
│ 👤 相关人物：黄遵宪/杨圭/侯安国   │
│ 🔗 资料来源：南方+《"一城两坊"   │
│    探源》 ↗（点击打开原文链接）   │
└──────────────────────────────┘
```

**source 字段结构**（全数据统一）：

```jsonc
"source": {
  "name": "南方+《\"一城两坊\"探源》",   // 来源名称（用于展示）
  "url": "https://static.nfapp.southcn.com/...",  // 链接（可点击追溯）
  "quote": "元朝天历三年，杨圭竖立'攀桂坊'坊表"   // 原文关键句（用于核验）
}
```

## 三、数据文件 → 地图图层的映射表

| 数据文件 | 空间形态 | 地图图层 | 点击交互 |
|---|---|---|---|
| `meizhou_timeline_v2.json` | 节点内 `pois[]`（POI+AOI 混合） | 随年份 filter 显示 | 故事卡 |
| `meizhou_people.json` | `home`→POI；`career[]`→PATH | circle + bezier 弧线 | 人物卡 + 弧线动画 |
| `meizhou_events.json` | `geo`→POI 或 AOI | 事件标记 + 定位 | 事件卡 |
| `meizhou_wards.json` | `aoi.geom`→面；`buildings[]`→POI；`gates[]`→POI | fill/line + circle | 坊巷卡（含科甲统计） |
| `meizhou_city_timeline.json`（旧） | `wall.geom`→AOI；`urbanGrowth`→AOI | 城垣/城区面 | 时间轴节点卡 |

## 四、渲染分层建议（MapLibre）

```
图层栈（自下而上）：
┌─ 底图：区县界 + 河流（现有，不动）
├─ ① 历史 AOI 层（坊巷/城墙圈/遗址带）→ fill 半透明 + line 描边，国风色
├─ ② 现代城区层（urbanGrowth）→ 按年份 setData
├─ ③ 城垣层（wall 多边形，现有逻辑）→ 2D fill / 3D extrusion
├─ ④ POI 层（城门/建筑/故里）→ circle + DOM Marker 标签
├─ ⑤ 路径层（人物弧线/迁徙线）→ Canvas overlay 或 GeoJSON line
└─ ⑥ 交互层：点击命中（queryRenderedFeatures）→ 弹故事卡
```
