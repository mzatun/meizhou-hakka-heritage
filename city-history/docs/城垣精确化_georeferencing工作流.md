# 梅州城垣精确化 · GeoReferencing 工作流

> 目标：把《嘉应州志》城池图 / 民国老地图 / 现代实测图进行地理配准，输出可替换当前示意性城垣的 GeoJSON，让时间轴上的城垣扩张真正“落在正确位置”。

---

## 一、为什么要做

当前原型里的城垣是用**周长反推的近似矩形**（1052 土城 1499 m、1385/1733 砖城 3280 m），只能表达“城有多大”，不能表达“城在哪、门朝哪、坊巷怎么排”。

精确化后能做到：
- 北宋土城、明砖城、清末东街西街、民国城墙拆除范围**逐一叠加**
- 城门、衙署、学宫、金山顶等**地标与城墙相对位置准确**
- 2D/3D 模式下城垣挤出能**贴合真实地形与河流**

## 三、配准技术路线（QGIS / ArcGIS Pro）

### 3.1 扫描与预处理
1. 扫描分辨率 ≥ 300 dpi，保存为 TIFF / PNG（带透明通道更佳）。
2. 若图为册页折痕严重，先用 Photoshop/GIMP 做**透视校正**（拉平页面）。
3. 裁剪掉边框、页码，只保留城池图主体。

### 3.2 选择地面控制点（GCP）
挑选**古今位置不变或变化极小**的地标作为控制点：

| 地标 | 古今状态 | 用途 |
|---|---|---|
| 金山顶 | 老城制高点，位置稳定 | 东北角锚点 |
| 梅州学宫（孔庙） | 宋以来地址未大移 | 城内中心锚点 |
| 凌风东路 / 仲元路 路口 | 民国骑楼街，仍可对应 | 东南/南部门区 |
| 梅江桥北桥头 | 1931 年建桥后位置稳定 | 城南临梅江锚点 |
| 曾井（遗址） | 古城区水井 | 城西锚点 |
| 东山书院 | 清乾隆年间建，位置稳定 | 城东锚点 |

> 控制点数量：至少 6–8 个，均匀分布在图的四角与中心。投影选 **WGS84 / EPSG:4326**（与当前 GeoJSON 一致）。

### 3.3 配准操作（QGIS）
1. `Raster` → `Georeferencer` → 打开扫描图。
2. 在图上点选 GCP，输入对应 WGS84 经纬度（从高德/天地图拾取）。
3. 变换类型：
   - 老地图变形大 → **二阶多项式（Polynomial 2）**
   - 现代实测图 → **仿射（Affine）**
4. 重采样：`Nearest Neighbor`（保持线条清晰）。
5. 保存配准后的 GeoTIFF。

### 3.4 数字化城墙与街坊
1. 以配准后的 GeoTIFF 为底图，新建 GeoJSON 图层。
2. 数字化以下要素：
   - `wall_ancient`：北宋土城 / 明砖城 / 清末城墙（Polygon）
   - `gates`：城门位置（Point），属性含 `name`（东门、上南门等）
   - `wards`：东街、西街、攀桂坊、红杏坊等街坊（Polygon）
   - `water`：城内曾井、护城河等（Point / Line）
   - `city_1937`：民国城墙拆除后城区范围（Polygon）
3. 导出为 `meizhou-walls-georeferenced.geojson`。

## 四、数据格式与前端接入

### 4.1 前端占位文件

已创建：`prototype/meizhou-walls-geo.js`

加载后会设置全局：

```js
window.MZ_WALLS_GEO = {
  type: "FeatureCollection",
  features: [
    { type: "Feature", properties: { year: 1052, name: "土城", material: "土城" }, geometry: { type: "Polygon", coordinates: [...] } },
    ...
  ]
};
```

### 4.2 index.html 接入逻辑

已修改 `prototype/index.html`：
- 优先读取 `window.MZ_WALLS_GEO`，若存在则用它绘制城垣；
- 若不存在，则回退到 `meizhou-data.js` 里的示意性 `wall.geom`。

这样你只要把配准后的 GeoJSON 粘贴进 `meizhou-walls-geo.js`，地图立即精确化，无需改代码。

### 4.3 GeoJSON 属性约定

```json
{
  "type": "Feature",
  "properties": {
    "year": 1052,
    "name": "北宋土城",
    "material": "土城",
    "perimeterM": 1499,
    "gates": 4,
    "source": "乾隆嘉应州志·城池图"
  },
  "geometry": { "type": "Polygon", "coordinates": [[...]] }
}
```
