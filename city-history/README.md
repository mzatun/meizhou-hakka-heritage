# 梅州 · 城市千年变迁（故事地图）

从程乡到世界客都：479-2026 城市千年变迁交互式故事地图。

**技术栈**：MapLibre GL（单文件可离线）+ Canvas 2D 双原型 · 国风 UI · 数据驱动时间轴

**功能**：
- 时间轴（479→2026，12 节点播放）+ 底图时间态化（现代/明清淡化/历史示意三模式）
- 古地图叠加：清代舆地图（州域）+ 咸丰城池图（州城），可调透明度/坐标微调
- 故事层：50+ POI（城门/坊巷/建筑/人物）+ 国风图标 + 历史图片 + 可追溯资料来源
- 全市域县区截面：兴宁/大埔/五华/平远/蕉岭/丰顺建置沿革随主时间轴联动
- 建县时序条、城区年轮式扩张、科举桑基图（CBDB）

**数据**：data/（时间线/人物/事件/县区/罗香林迁徙）+ docs/（技术文档、学术史料、升级报告）

> 演示用途，古地图/老照片版权归原作者（梅州日报等），教学使用。
