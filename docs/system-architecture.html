系统架构与资源说明

本页说明《梅州客家非遗》沉浸式数字课程门户的技术栈、目录结构、模块职责、数据流、AI 能力映射与扩展方式，供维护与二次开发参考。

一、技术栈

  • 纯静态前端：HTML5 + CSS3 + 原生 JavaScript（ES2020），无打包、无框架、无构建步骤，可直接静态托管。
  • 地图：Leaflet 1.9.4（通过 CDN 引入），配合在线瓦片底图渲染客家迁徙与梅州非遗分布。
  • 背景乐：Web Audio API 实时合成五声音阶山歌风味旋律（竹笛音色模拟 + 低音持续音 + 简易混响），零音频文件依赖，可静音。
  • 文生语音：浏览器内置 Web Speech API（SpeechSynthesis，中文 zh-CN）实现讲解稿朗读与对话播报。
  • 数据：课程章节、城市节点、器物、问答均以 JSON 存放，运行时由 fetch 加载并带内存缓存。
  • 视觉素材：封面、章节图、讲解员立绘、40 件长廊器物均由 AI 文生图生成，统一存放于 assets/img/。

三、模块职责

模块职责关键接口

四、数据流

页面脚本调用 loadData("chapters"|"cities"|"relics"|"qa") → fetch("data/xxx.json") → 解析为对象并缓存 → 渲染到 DOM（章节卡片、地图标记、长廊翻转卡、讲解员应答）。由于使用 fetch，站点需经 HTTP 服务访问（已通过静态服务器部署，本地可用 python -m http.server 预览）。

五、AI 能力映射与务实替代

需求实现方式说明
封面/章节/长廊图AI 文生图（已生成 PNG）统一存于 assets/img，路径写入 JSON
山歌风味背景乐Web Audio 实时合成五声旋律可静音；如需真实音频，替换 assets/audio 并改 bgm.js
文生语音朗读Web Speech API（zh-CN）依赖浏览器语音引擎；可换云端 TTS
AI 讲解员对话本地知识库 qa.json 意图匹配零后端；可接入大模型 API 升级为自由问答
章节短视频封面图 Ken Burns / Canvas 画卷如需真实文生视频，补充 mp4 并在 chapter.html 嵌入

六、如何扩展

  • 新增章节：在 data/chapters.json 的 chapters 数组追加对象（含 no/title/subtitle/period/level/summary/keywords/cover/scene/points/script），并放入对应封面 assets/img/covers/cN.png。
  • 新增地图节点：在 data/cities.json 的 route/counties/spread/overseas 中追加（含 name/lat/lng/...，坐标用 WGS84）。
  • 新增长廊器物：在 data/relics.json 追加 rXX 对象并放入 assets/img/relics/rXX.png。
  • 扩充讲解员知识：在 data/qa.json 增加问答对（keywords + answer）。
  • 重生成讲义/课件：修改 refs/build_docs.py 后运行 python refs/build_docs.py。
