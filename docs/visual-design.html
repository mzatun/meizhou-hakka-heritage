设计文档

视觉规范与交互语言

全站以「博物馆级东方叙事」为基调：靛蓝为骨、夯土黄为暖、焰红为魂，强调中文排版留白、衬线气质与丝滑过渡。

一、三色主视觉

靛蓝 Indigo #24466b 夯土黄 Earth #c9973f 焰红 Flame #d45a3a

色角色典型用途
靛蓝 #24466b主色 / 暗底背景、标题、地图迁徙线、卡片结构
夯土黄 #c9973f强调 / 暖金导航高亮、描金标题、按钮、数据数字、光点
焰红 #d45a3a点睛 / 火火龙粒子、强调标签、提示语、关键数字
宣纸 #f2e8d5浅底讲义页、说明文档、长廊留白区

二、字体与排版

  • 衬线（标题/正文重音）：Noto Serif SC，回退 Songti SC / STSong / SimSun，营造碑刻与典籍气质。
  • 无衬线（辅助/界面）：Noto Sans SC，回退 PingFang SC / Microsoft YaHei。
  • 主标题描金：.gold-text 用渐变 + 文字阴影模拟金箔质感（夯土黄→浅金→暗金）。
  • 中文留白：正文行高 1.9，段间距宽松；小标题用 .kicker 大字距（letter-spacing .4em）配短线分隔，强调呼吸感。

三、栅格与留白

内容容器 .wrap 最大宽度约 1120px 居中；区块 .section 上下留白充足（桌面 ≥72px）。移动端单列堆叠，卡片网格自适应。

五、核心组件

  • 导航：固定顶栏，半透明 + 毛玻璃，当前页 .active 高亮夯土黄。
  • Hero：全屏背景图（home-cover.png）+ 暗纱 + 画布 + 描金大标题 + 三入口 CTA。
  • 章节卡 / 详情：时间轴节点 + 立体封面卡；详情页含讲解稿、听讲解（TTS）、场景缩放。
  • 地图：Leaflet 标记三色分级（迁徙/县区/播迁），点击弹城市卡片含概况、代表非遗与章节跳转。
  • 翻转卡：瀑布流中的每件器物可点击翻转，背面为断代/工艺/流传/谱系/故事。
  • AI 讲解员：右下角常驻头像（蓝衫客家妹子立绘），展开对话面板，流式打字 + 语音播报。

六、响应式与无障碍

  • 断点：桌面 ≥1024px 多列；平板 640–1024px 两列；手机 <640px 单列。
  • 尊重 prefers-reduced-motion，可关闭大幅动效。
  • 背景乐默认静音，需用户手势触发（满足浏览器自动播放策略）。
  • 语义化标签 + aria-label，保证键盘可达。
